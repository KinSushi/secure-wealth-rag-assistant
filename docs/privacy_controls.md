# Privacy Controls

| Control | Purpose |
|---|---|
| Synthetic corpus only | Prevent private data exposure |
| PII pattern detection | Detect accidental PII-like strings |
| No private uploads | Avoid confidential document ingestion |
| Citation-grounded answers | Reduce unsupported output |
| Human review policy | Escalate sensitive cases |

Forbidden data:

- real client profiles;
- account numbers;
- insurance policies;
- health records;
- identity documents;
- contracts;
- private PDFs.
